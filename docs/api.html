Reference

API reference

Everything the RepoAtlas app does goes through a documented REST API. The endpoint reference below is rendered in your browser from openapi.json, which CI regenerates from the backend on every docs deploy, so it always matches the code.

Basics

Base URLhttps://<your-api-host> — every path starts with /api/v1. Locally: http://localhost:8000.
FormatJSON request and response bodies (Content-Type: application/json); responses over 1 kB are gzip-compressed when the client accepts it.
SchemaOpenAPI 3.1. A running server also serves its own document at /openapi.json and FastAPI's interactive explorers at /docs and /redoc.
TracingSend X-Request-ID (1–128 chars of A–Z a–z 0–9 . _ : -) to correlate logs; otherwise one is generated. It is always echoed in the response headers.
CORSBrowser origins must be listed in the server's CORS_ORIGINS; any localhost port is allowed in development.

Authentication

Authenticated calls send a Supabase access token: Authorization: Bearer <token> (the frontend gets it from the signed-in Supabase session). Each endpoint below shows one of three levels:

BadgeMeaning
PublicNo token needed.
Auth optionalWorks anonymously; with a token the caller is identified (e.g. own private tours are included). An invalid or expired token is still rejected with 401.
Auth required401 UNAUTHORIZED without a valid token. Owner-only actions return 403 FORBIDDEN for other users, and private tours of other users are 404 NOT_FOUND.

Response envelope

Every response — success or error — has the same shape. Clients check success and read either data or error.

{
  "success": true,
  "data": { "version": "0.1.0", "ai_enabled": false, "max_files": 1500, "github_authenticated": true },
  "error": null
}
{
  "success": false,
  "data": null,
  "error": {
    "code": "ANALYSIS_NOT_READY",
    "message": "Analysis is PARSING_AST",
    "details": { "status": "PARSING_AST" }
  }
}

Request validation failures use the same envelope with VALIDATION_ERROR and details.errors, a list of {loc, msg, type} (the submitted input is never echoed). Unexpected server errors return INTERNAL_ERROR with details.request_id; stack traces are never exposed.

Error codes

Domain errors come from core/errors.py; the HTTP status is fixed per code unless noted.

CodeHTTPMeaning
VALIDATION_ERROR422Request body / query / path failed validation, or a semantic check (e.g. reorder list incomplete, checkpoint index out of range). Framework-level 400 responses also carry this code (with status 400).
INVALID_REPO_URL422The repository URL or owner/repo could not be parsed.
UNAUTHORIZED401Missing, malformed, expired or invalid bearer token where one is required (or any invalid token).
FORBIDDEN403Authenticated, but not the owner of the tour.
NOT_FOUND404Unknown analysis, repository, tour, step or branch — or another user's private tour.
CONFLICT409State conflict: answering out of order, resolving a step that does not need it, accepting a missing proposal, keeping lines of a deleted file.
ANALYSIS_NOT_READY409The analysis has not reached COMPLETED (details.status), or a sync is still waiting for the new commit.
GITHUB_REPO_NOT_FOUND404GitHub has no such public repository (or it is private).
GITHUB_RATE_LIMITED429GitHub API quota exhausted; details.reset_at, details.authenticated.
GITHUB_UNAVAILABLE502GitHub errors or timeouts after retries, or an unreadable archive.
REPO_TOO_LARGE413The source archive exceeds MAX_TARBALL_BYTES (details.max_tarball_bytes).
NO_SOURCE_FILES422No supported Python/JS/TS files, or an empty repository.
FILE_NOT_IN_SNAPSHOT404The path is not part of the analysis (details.path).
INVALID_LINE_RANGE422Lines outside the file (details.loc, start_line, end_line).
AI_DISABLED503AI drafting is not configured (no GEMINI_API_KEY).
AI_FAILED502 · 429The model call failed or returned unusable output; 429 with details.retry_after when the per-user limit (20 uncached drafts per 10 minutes) is hit.
SERVICE_UNAVAILABLE503Database unreachable (health check) or Supabase JWKS could not be fetched.
INTERNAL_ERROR500Unexpected error (details.request_id); also stored on analyses that crashed or exhausted their attempts.

Framework-level responses use the same envelope: METHOD_NOT_ALLOWED (405), NOT_IMPLEMENTED (501) and HTTP_ERROR for any other 4xx; unknown routes return NOT_FOUND with “Route not found”.
